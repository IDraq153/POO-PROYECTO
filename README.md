# 🏨 Hotel Room Management System

![Java](https://img.shields.io/badge/java-%23ED8B00.svg?style=for-the-badge&logo=openjdk&logoColor=white)
![NetBeans IDE](https://img.shields.io/badge/NetBeans_IDE-%231B6AC6.svg?style=for-the-badge&logo=apache-netbeans&logoColor=white)
![POO](https://img.shields.io/badge/Paradigma-POO-green?style=for-the-badge)

Este proyecto consiste en un sistema de escritorio desarrollado en **Java** utilizando el IDE **NetBeans**. Su objetivo es gestionar de manera eficiente el control de habitaciones, huéspedes y estados de ocupación de un hotel, aplicando de forma estricta los pilares de la **Programación Orientada a Objetos (POO)**.

---

## 🎯 Objetivos de la Arquitectura (POO)

El diseño del software se estructuró bajo principios robustos de ingeniería de software:
* **Encapsulamiento:** Protección de los datos críticos de habitaciones y huéspedes mediante el uso estricto de modificadores de acceso (`private`) y métodos de acceso (`getters/setters`).
* **Abstracción y Modularidad:** Representación clara de entidades del mundo real en clases independientes (`Habitacion`, `Huesped`, `Reserva`).
* **Reutilización de Código:** Optimización de la lógica del negocio mediante relaciones de asociación y composición entre objetos.
